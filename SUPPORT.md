# Support

For a reproducible defect, use the repository's bug-report form once it is available. Include safe, redacted reproduction details; do not use an Issue for general questions.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) rather than opening a public Issue.

For conduct concerns, follow [CODE_OF_CONDUCT.md](https://github.com/SofiaFlux/summa42/blob/main/CODE_OF_CONDUCT.md).

General support is unavailable until GitHub Discussions has been enabled and verified. This experimental, local-first MVC does not offer hosted support or a response-time commitment.
